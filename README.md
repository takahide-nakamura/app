# もっと住みやすい高槻へ

「もっと住みやすい高槻へ」は、高槻市をより住みやすいまちにするための政策提案・活動報告・情報発信を行うWebサイトです。

理学療法士としての現場経験と、公的資料・研究・市民の声をもとに、事実を分かりやすく整理し、具体的な政策として提案することを目的としています。

---

# サイトの目的

このサイトは「政治家の名刺」ではありません。

市民が必要な情報へ迷わずたどり着き、政策を理解し、活動を知り、意見を届けられる「政策プラットフォーム」を目指しています。

目的は次の5つです。

- 信頼を得る
- 政策を理解してもらう
- 活動を知ってもらう
- 市民との対話につなげる
- 長期的な情報資産として育てる

# 品質基準

このサイトは次の品質を目標としています。

- 初めて見た人でも迷わない
- 高齢者でも読みやすい
- スマートフォンで快適に利用できる
- 数年後も更新しやすい
- 検索で見つけてもらいやすい
- 出典が明確で信頼できる
- AIと相性が良い構造
- 選挙後も価値が残る
- 市民が何度も訪れたくなる
- YouTube・X・Instagram・note と相互に連携できる

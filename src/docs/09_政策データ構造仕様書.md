# 政策データ構造仕様書

この文書は、政策・活動・出典のデータ構造の正式な意味と運用ルールを定義します。実装上の厳密な型は [src/content.config.ts](src/content.config.ts) を参照してください。

---

## 1. Content Collection の役割

- policies: 政策ページの本文・評価・提案などを管理する
- activities: 活動の要約・更新日・公開状態を管理する
- sources: 出典・資料メタデータを管理する

## 2. Policy の主要フィールド

- title: 政策名
- description: 1 文の要約
- heroTitle: ヒーローに表示するタイトル
- heroDescription: ヒーローに表示する補足説明
- category: 政策カテゴリ
- tags: 検索・整理用タグ
- updated: 更新日（YYYY-MM-DD）
- relatedActivities: 関連活動への参照
- references: 参考資料への参照
- youtube: YouTube 動画のタイトルと URL
- problem: 問題提起の段落
- evaluation: 主観評価・客観評価のブロック
- issues: 課題の一覧
- proposals: 政策提案の一覧
- limitations: 制約・限界の段落

## 3. Activity の主要フィールド

- title: 活動名
- summary: ひとことで説明する要約
- updated: 更新日（YYYY-MM-DD）
- status: published / draft

## 4. Source の主要フィールド

- title: 資料名
- publisher: 発行主体
- year: 発行年
- url: 資料 URL

## 5. 運用ルール

- 既存フィールドを勝手に増やさない
- relatedActivities と references には実在する ID を使う
- 事実・評価・提案を混同しない
- フィールド名・型・参照関係を変える場合は、仕様書と実装を同時に更新する

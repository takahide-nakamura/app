# アクセシビリティチェック

この文書は、サイトを多くの人が読める状態に保つための最低基準を定義する。見た目の好みよりも、読みやすさと理解しやすさを優先する。

---

## 1. 必須チェック項目

以下は、すべての更新時に確認する。

- 見出しが h1 → h2 → h3 の順である
- 色だけで意味を伝えていない
- リンクテキストが「こちら」などの曖昧な表現になっていない
- 本文が読みやすい行間と長さになっている
- 画像やアイコンに意味がある場合は、テキストでも補足する
- ボタンやリンクが押しやすいサイズである

## 2. 文章のアクセシビリティ

- 1文を長くしすぎない
- 専門用語は必要に応じて説明する
- 箇条書きは読みやすい粒度に分ける
- 大事な情報は冒頭に置く
- 重要な説明を画像や色に依存しない

## 3. 見出しのルール

- 1ページにつき1つの h1 を使う
- h2 は章単位で使う
- h3 は内容ごとの小見出しとして使う
- 見出しが飛んでいても、順番を飛ばさない

## 4. 文字と視認性

- コントラストは十分に確保する
- 文字サイズを小さくしすぎない
- まとまった段落を避け、読みやすい塊にする
- 重要なリンクには視認しやすい文字色を使う

## 5. 禁止事項

- 色だけで状態や意味を伝えない
- アイコンだけで重要情報を示さない
- 文章の説明なしに、図や絵だけで意味を伝えない
- リンクの見た目を荒くし、どこを押すか分かりにくくしない

# アクセシビリティチェック

この文書は、誰でも読みやすく使いやすいサイトを維持するための基準です。

---

## 1. 基本方針

- 色だけで意味を伝えない
- 文字サイズと行間を読みやすい状態に保つ
- 見出し構造を順番に保つ
- リンクテキストは内容が分かるものにする
- 画像には適切な alt を付ける

## 2. チェック項目

- 見出しが順番通りになっているか
- 本文が十分に読みやすいか
- リンクが「こちら」だけになっていないか
- ボタンやリンクが押しやすいサイズか
- 画面幅が狭くても内容が崩れないか
- 文字と背景のコントラストが十分か

## 3. 実装上の注意

- アイコンだけで意味を伝えない
- 装飾画像には空の alt を使う
- 重要な情報は文章でも補足する

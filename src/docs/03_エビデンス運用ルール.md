# エビデンス運用ルール

この文書は、政策内容の信頼性を維持するために、根拠・出典・事実の扱いを統一するためのルールです。

---

## 1. 根拠の優先順位

根拠は、原則として次の順で優先します。

1. 法律・条例
2. 公的資料
3. 公的統計
4. 学術論文
5. 国際機関資料
6. 信頼できる二次資料

## 2. 事実・評価・提案の区別

- 事実: 公的資料や統計に基づく内容
- 現場経験: 個人・現場の経験に基づく内容
- 評価: 事実から導かれる解釈
- 提案: 政策改善の方向性

これらを混同しないことが重要です。

## 3. 出典の基本情報

各根拠は、可能な限り次の情報を明示します。

- 資料名
- 発行主体
- 年度または発行年
- URL

## 4. AI 生成情報の扱い

AI が生成した情報は、直接の根拠として扱いません。一次資料または信頼できる公式資料で確認した内容のみを採用します。

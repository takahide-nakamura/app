# エビデンス運用ルール

この文書は、政策の主張を支える根拠の扱いを定義する。根拠がない内容を政策として扱わないことを原則にする。

---

## 1. 根拠の優先順位

情報は、次の順で優先する。

1. 法律・条例
2. 政府・自治体の公的資料
3. 学術論文
4. 国際機関の資料
5. 研究や報告書
6. それ以外の二次資料

上位の根拠があれば、下位の資料を補足として使うが、根拠の置き換えにはしない。

## 2. 事実・評価・提案の分離

次の区別を必ず守る。

- 事実: 公的資料や統計などに基づく説明
- 現場経験: 現場で感じたことや実感
- 評価: 事実から導かれる判断
- 提案: 改善策や政策案

「事実」を含まない主張を、政策の根拠として扱ってはいけない。

## 3. 参考資料の必須条件

各根拠は、少なくとも次の情報を保持する。

- 資料名
- 発行主体
- 発行年または更新年
- URL

source ファイルは [src/content/sources](../content/sources) に配置し、title, publisher, year, url を使う。

## 4. AI と生成文の扱い

- AI が生成した文章は、直接の根拠として扱わない
- 出典の確認ができない内容は記載しない
- 確認途中の内容がある場合は、書かずに未確認と明示する
- 「おそらく」「たぶん」などの曖昧表現を、根拠のない断定として書かない

## 5. 禁止事項

- 根拠のない政策主張を載せない
- 公的資料を見ずに、個人の感想を事実として書かない
- 出典フェーズを省略する
- 参考資料を作り替えて、元資料の意味を変えない

## 6. 記載方法の具体例

- 正しい: 「東京都の資料では、〇〇と報告されている」
- 誤り: 「私の経験から、〇〇は明らかだ」
- 誤り: 「AI の判断では、〇〇は深刻だ」

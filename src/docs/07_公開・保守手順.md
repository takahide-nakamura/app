# 公開・保守手順

この文書は、コンテンツやコードを変更したときに、確認すべき手順をまとめたものです。

---

## 1. 基本作業手順

1. 変更対象を特定する
2. 関連する仕様・実装・データを確認する
3. 変更内容を小さく保つ
4. ローカルで確認する
5. ビルドを実行する
6. 必要に応じて公開する

## 2. 変更対象の確認場所

- 政策追加・修正: [content/policies](../content/policies)
- 活動追加・修正: [content/activities](../content/activities)
- 出典追加・修正: [content/sources](../content/sources)
- スキーマ変更: [content.config.ts](../content.config.ts)
- 表示変更: [components](../components) / [pages](../pages)

## 3. ローカル確認

- npm run dev で表示を確認する
- npm run build で静的生成を確認する
- 参照リンクや表示崩れがないか確認する

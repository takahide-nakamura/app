# CHANGELOG

この文書は、「もっと住みやすい高槻へ」サイトの主要な変更履歴を記録するものです。

細かな修正はGitのコミット履歴で管理し、この文書には設計変更・ページ追加・機能追加など、重要な変更だけを記録します。

---

# 記載ルール

変更内容は次の区分で整理します。

* Added：新しく追加したもの
* Changed：既存内容を変更したもの
* Fixed：不具合を修正したもの
* Removed：削除したもの
* Planned：今後予定しているもの

新しい変更を上に追加します。

# UI・デザインルール

この文書は、サイトの見た目と情報構造が一貫するようにするためのルールです。実装の細部ではなく、表示の基本方針を定義します。

---

## 1. 基本方針

- 読みやすさを最優先する
- スマートフォンで読めることを前提にする
- 情報の見出しと本文が自然につながる構造にする
- 既存のコンポーネントを再利用する

## 2. 政策ページの基本構造

政策ページでは、次の順で読める構造を基本とします。

1. 見出し
2. 概要
3. 問題・評価・課題・提案
4. 関連活動
5. 参考資料

## 3. 現行コンポーネントの使い方

- PolicySection: セクション見出しと区切り
- EvidenceBox: 評価・補足・留意点の整理
- RelatedActivities: 関連活動の案内
- ReferenceList: 参考資料の案内
- YouTubeLink: 動画への導線

## 4. 変更時の注意

- 見た目だけの変更ではなく、情報の整理にもつなげる
- 既存のレイアウトやコンポーネントの意味を壊さない
- 新しい情報構造を追加する場合は、既存のページ構成との整合性を確認する

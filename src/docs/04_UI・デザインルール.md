# UI・デザインルール

この文書は、情報を見やすく伝えるための表示ルールを定義する。見た目よりも、読みやすさと意味の明確さを優先する。

---

## 1. 基本ルール

- 1ページあたりの情報量を増やしすぎない
- 章立ては h2 / h3 を順番通りに使う
- 色だけで意味を伝えない
- 既存のコンポーネントを使ってレイアウトを統一する
- スマートフォンで読めることを前提にする

## 2. 政策ページの表示順序

政策ページの見出し構造は、次の順番を基本とする。

1. 政策タイトル
2. 概要
3. 問題提起
4. 評価
5. 課題
6. 提案
7. 制約・限界（必要な場合）
8. 関連活動
9. 参考資料

この順序を変えると、情報の読み順が崩れるため、原則として変更しない。

## 3. 用いるコンポーネント

現行実装では、次のコンポーネントを使う。

- PolicySection: セクションの見出しと区切り
- EvidenceBox: 評価・補足・留意点の整理
- RelatedActivities: 関連活動の案内
- ReferenceList: 参考資料の一覧表示
- YouTubeLink: 動画への導線

### 禁止事項

- 箇条書きの意味を変える
- 既存のコンポーネント名と役割を別物に扱う
- 見た目だけで情報の階層を変える

## 4. 見た目の守るべき制約

- 見出しと本文の間隔を崩さない
- 文字が詰まりすぎない
- 新しい色や新しいアイコンを無闇に増やさない
- 伝えたい内容が、文章で説明できない見た目にしない

## 5. 変更時の確認事項

UIを変えるときは、次を確認する。

- 政策の読み順が変わっていないか
- 関連活動や参考資料が見切れていないか
- 見出しが適切な階層になっているか
- 文字が小さすぎて読みづらくなっていないか

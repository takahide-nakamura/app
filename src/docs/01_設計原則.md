# 設計原則

この文書は、このサイトの「変わらない方針」を定義します。長期運用を前提にしており、実装の詳細や日々の作業手順は別文書で管理します。

---

## 1. サイトの役割

このサイトは、政策・活動・出典を整理して市民に伝えるための情報基盤です。プロフィール紹介だけではなく、次の価値を重視します。

- 政策の背景と課題を理解しやすくする
- 根拠となる出典を明示する
- 住みやすさに関する活動を見つけやすくする
- 長期的に更新しやすい構造にする

## 2. 基本原則

- 事実・評価・提案を分ける
- 文章は短く、読みやすくする
- 根拠がある内容を優先する
- データと表示を分離する
- 変更前に影響範囲を確認する
- AI と人間が共同で保守する前提で設計する

## 3. 現行実装との関係

このプロジェクトでは、Astro + TypeScript + Content Collections を用いています。コンテンツは Markdown とスキーマで管理し、表示は Astro コンポーネントで組み立てます。

- 政策、活動、出典はそれぞれ独立した Content Collection として扱う
- 政策と活動・出典の関係は Content Collection reference で表現する
- 表示の差分はコンポーネント側で吸収する

## 4. 文書の責務分担

- 01 設計原則: 変わらない方針
- 02 コンテンツ執筆ルール: 文章の書き方
- 03 エビデンス運用ルール: 根拠・出典の扱い
- 04 UI・デザインルール: 表示構造と見た目の基本
- 05 アクセシビリティチェック: 利用しやすさ
- 06 SEO・情報設計: 発見しやすさと整理のしやすさ
- 07 公開・保守手順: 更新・確認・公開手順
- 08 AI運用ルール: AI の作業方法
- 09 政策データ構造仕様書: データ構造の正式仕様

# コンテンツ執筆ルール

この文書は、政策・活動・出典の文章が一貫した品質で書けるようにするためのルールです。実装の詳細ではなく、書き方の基準を定義します。

---

## 1. 基本方針

- 短く、明確な文章を使う
- 事実と評価を分ける
- 専門用語には必要に応じて説明を付ける
- 断定しすぎず、根拠に基づいて記述する
- 読み手の負担を減らすため、段落を分ける

## 2. 文体

- 基本は「です・ます調」にする
- 1 文を長くしすぎない
- 不確実な内容は「〜と考えられます」などで表現する

## 3. 政策ページの基本構成

政策本文は、次の順で読みやすく整理することを基本とします。

1. 問題提起
2. 評価
3. 課題
4. 政策提案
5. 限界・留意点（必要な場合）
6. 参考資料

## 4. 文章の種類ごとの注意

### 政策本文
- 目的・課題・提案が明確に伝わるようにする
- 批判だけでなく改善方向を示す

### 活動本文
- 事実と現場経験を混ぜない
- 何をしたか・何を学んだかを明確にする

### 出典・資料説明
- 資料名・発行主体・年・URL が分かるようにする

# SEO・情報設計

この文書は、検索されやすく、長期的に評価されるサイトを維持するためのルールを定めます。

---

# 基本方針

SEOを目的としません。

市民に役立つ情報を作ることを目的とします。

結果として検索評価を得ることを目指します。

---

# URL

URLは公開後できるだけ変更しません。

英語スラッグを使用します。

例

/policy/noise

/policy/garbage

---

# タイトル

タイトルは30文字程度を目安とします。

検索結果で意味が伝わる文章にします。

---

# description

すべてのページにdescriptionを設定します。

120文字程度を目安とします。

---

# 見出し

ページごとにh1は1つだけ使用します。

---

# カテゴリ

カテゴリは固定します。

新しいカテゴリは原則追加しません。

---

# タグ

タグを充実させます。

検索性向上のため積極的に活用します。

---

# 内部リンク

関連政策

関連活動

プロフィール

問い合わせ

などへ自然にリンクします。

---

# 出典

参考資料を掲載します。

検索エンジンだけでなく、市民からの信頼向上を目的とします。

---

# AI検索

AIによる検索・要約を前提とします。

そのため

- 見出し
- 箇条書き
- 明確な構造

を維持します。

---

# 更新

情報更新日を管理します。

古い情報は放置しません。

---

# 目標

市民が検索したとき

「高槻市 ○○」

で見つけてもらえるサイトを目指します。

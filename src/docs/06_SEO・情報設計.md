# SEO・情報設計

この文書は、サイト内の情報が見つけやすく、整理しやすく、AI や検索エンジンにも適した形になるように定める。SEO を目的にせず、情報の整理を目的とする。

---

## 1. 基本原則

- タイトルと説明文は簡潔にする
- 1ページに1つの h1 を使う
- 見出しは内容をそのまま表す
- 政策・活動・出典の関係が追えるようにする
- 関連ページへの導線を自然に設ける

## 2. 政策ページの基本情報設計

政策ページは、次の情報を明確に持つ。

- title
- description
- heroTitle
- heroDescription
- category
- tags
- relatedActivities
- references

情報が不足していると、検索や紹介の文脈が弱くなるため、主要項目は必ず埋める。

## 3. 見出しと文章の構造

- 1ページの見出し順は揃える
- 内容ごとに h2 を使う
- 概要は最初に置く
- 参考資料は最後に置く
- 提案や課題は、文章の流れが追えるように並べる

## 4. 関連リンクの設計

- 政策と関連活動は関連付ける
- 政策と出典は references で結ぶ
- 過度に離れたページへの飛び先を増やさない
- すべての関連リンクは、実在する ID と一致させる

## 5. 禁止事項

- title と description を省略する
- 複数の h1 を使う
- 章の順序を勝手に変える
- 関連ページが実在しないのに、見出しだけ作る
- SEO のためだけに、内容の意味を変える

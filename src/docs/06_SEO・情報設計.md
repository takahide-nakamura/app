# SEO・情報設計

この文書は、検索や AI 検索で見つけやすく、整理しやすい構造を維持するためのルールです。

---

## 1. 基本方針

- SEO を目的化しない
- 市民に役立つ情報を優先する
- その結果として検索・要約・再利用に強い構造を作る

## 2. 重要な要素

- URL は安定していること
- title と description は簡潔にする
- 1 ページにつき 1 つの h1 を使う
- 見出しは内容を表すものにする
- 関連政策・関連活動・参考資料へ自然にリンクする

## 3. コンテンツ構造

- 政策・活動・出典の関係が追えるようにする
- 重要な内容は見出しと箇条書きで整理する
- 参考資料は最後にまとめる

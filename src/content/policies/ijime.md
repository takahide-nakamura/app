problem:
  paragraphs:
    - "高槻市立小中学校におけるいじめの認知件数は増加しています。令和7年度は小学校898件、中学校623件、合計1,521件となり令和6年度1,300件、令和5年度の1,072件から増加しました。"
    - "一方で、認知件数が増えたことだけから、いじめそのものがどの程度深刻化しているのかを判断することはできません。高槻市教育委員会は、アンケート、教育相談、日常の児童生徒の観察、教員研修等によって、いじめの積極的な認知や早期発見・早期対応を進めていることを認知件数増加の背景として説明しています。"
    - "令和7年度には、いじめ防止対策推進法第28条に基づく「重大事態」として小学校3件、中学校3件、合計6件が調査され、令和6年度の10件から減少しています。ただし、重大事態の件数だけで、いじめへの対応状況や重大化の防止状況を評価することはできません。また、認知件数1,521件という数字だけでは、軽微な段階で発見された事案、継続的な支援が必要な事案、重大事態に至った事案の違いを市民が把握することは困難です。"
    - "いじめの認知件数を減らすことだけを目標にすると、早期発見のために必要な認知まで抑制してしまうおそれがあります。重要なのは、認知したいじめを適切に把握し、必要な支援につなげ、重大化を防ぎ、いじめが解消したことを確認した上で、その後も必要に応じて見守りを続けることです。"
    - "高槻市では、各学校のいじめ不登校対策委員会を中心とした組織的な対応に加え、必要に応じて教育指導課や高槻市学校問題解決チーム、スクールカウンセラー、スクールロイヤー等と連携する仕組みが設けられています。したがって、今後の課題は新しい組織を作ることだけではなく、既存の仕組みが、必要な事案に対して適切なタイミングで実際に機能しているかを検証することです。"
    - "また、インターネットやSNS上のいじめは、学校の中だけを見ていては把握しにくいという特徴があります。高槻市の学校いじめ防止基本方針でも、インターネット上の不適切な書き込みやSNS等への対応、保護者・教育委員会・警察等との連携が示されています。"
    - "「学校だけで抱え込まない」とは、学校の責任を教育委員会や専門職に移すことではありません。学校を中心に、教育委員会、SC、SSW、スクールロイヤー、医療・福祉・警察等が、それぞれの役割に応じて必要な支援を行い、学校だけでは対応が難しい事案を組織として支えることを意味します。"


evaluation:
  subjective:
    heading: "現場で感じること"
    paragraphs:
      - "いじめは、子ども同士のトラブルとして処理するだけでは、被害を受けた児童生徒の安全や安心が十分に確保されない場合があります。特に、本人が相談できない場合や、周囲が『大したことではない』と受け止めてしまう場合には、問題が見えにくくなります。"
      - "一方で、教職員にすべての調査、保護者対応、心理的支援、福祉的支援、法的対応まで求めることにも限界があります。教職員の負担を軽減しながら、子どもの小さな変化を見逃さず、必要な専門機関につなぐ仕組みを強化することが重要です。"
      - "いじめ対策と教職員の負担軽減は対立する課題ではありません。教職員が一人で問題を抱え込まない仕組みを整えることは、子どもへの対応を継続するためにも重要です。"
      - "いじめは被害児童生徒と加害児童生徒だけの問題ではなく、周囲の児童生徒がどのように反応するかも重要です。傍観者や観衆を含め、いじめを許容しない学級・学校風土を育て、児童生徒が困ったときに安心して声を上げたり、周囲の児童生徒が相談につなげたりできる環境を整える視点が必要です。"

  objective:
    heading: "公的資料から分かること"
    paragraphs:
      - "高槻市教育委員会による令和6年度の報告では、いじめの認知件数は小学校689件、中学校611件、合計1,300件でした。重大事態として調査した件数は小学校6件、中学校4件、合計10件でした。"
      - "高槻市教育委員会は、認知件数が増加している背景として、各校のいじめ防止基本方針に基づく日常的な観察、教育相談、アンケートによる早期発見・早期対応、教員研修等を挙げています。そのため、認知件数の増加をそのまま『いじめが増えた』と評価することはできません。"
      - "令和6年度に認知された1,300件について、高槻市教育委員会は、小学校では689件のうち450件がいじめ行為について解消、237件が取組中、中学校では611件のうち461件が解消、149件が取組中と報告しています。認知件数だけでなく、その後の対応状況を見ることが重要です。"
      - "高槻市の学校いじめ防止基本方針では、学校いじめ不登校対策委員会を中心とした組織的対応が位置付けられ、必要に応じて教育指導課や高槻市学校問題解決チームの専門家派遣を活用する仕組みが示されています。学校だけで解決が困難な事案について、教育委員会や関係機関と連携する仕組みは既に存在します。"
      - "文部科学省は、いじめの積極的な認知、早期発見・早期対応、いじめを重大化させない取組を重視しています。また、令和6年8月に改訂した『いじめの重大事態の調査に関するガイドライン』について、令和8年3月には平時からの備えを点検する取組を進めています。"
      - "文部科学省の令和6年度調査では、全国の小・中・高・特別支援学校におけるいじめ認知件数は約76万9千件、重大事態は1,405件で、いずれも過去最多となっています。全国的にも、認知件数の増加と重大事態への対応の両方を考える必要があります。"
      - "高槻市の学校資料では、インターネット上の不適切な書き込みやSNS等による問題について、学校だけでは把握しにくい特性を踏まえ、保護者や教育委員会、警察等との連携が示されています。したがって、ネット上のいじめについても実態把握と対応方法を継続的に検証する必要があります。"

issues:
  - title: "認知件数だけでは、いじめの実態を十分に評価できない"
    description: "認知件数の増加は、いじめの増加だけでなく、早期発見や積極的認知が進んだ結果でもあり得ます。一方で、認知した事案がどのような態様で、どの程度の支援を必要とし、どのくらいの期間で解消・継続支援となったのかは、認知件数だけでは分かりません。"

  - title: "重大事態を含めた対応状況を継続的に検証する必要がある"
    description: "重大事態の件数は重要な指標ですが、それだけでは学校や教育委員会の対応が適切だったかを評価できません。重大事態の疑いを把握した段階からの初動、児童生徒の安全確保、保護者への情報共有、必要な支援、調査、再発防止策等について、国のガイドラインに沿った対応が行われたかを検証する必要があります。文部科学省の「いじめの重大事態の調査に関するガイドライン」及びチェックリストを活用し、高槻市及び各学校における平時からの備え、重大事態発生時の対応手順、記録・情報共有の状況を定期的に点検します。"

  - title: "学校だけで問題を抱え込まない仕組みを実際に機能させる必要がある"
    description: "高槻市には学校いじめ不登校対策委員会、教育指導課、高槻市学校問題解決チーム等の仕組みがあります。新しい組織を作ることだけではなく、どのような事案をどの段階で教育委員会や専門家につなぐのかを明確にし、既存制度が適切に利用されているかを検証する必要があります。"

  - title: "教職員の負担と子どもの安全を両立させる必要がある"
    description: "いじめへの対応を教職員個人の努力に依存すると、対応の質と継続性の両方に影響する可能性があります。教職員がすべてを解決するのではなく、心理、福祉、法律、関係機関との連携を含めてチームで対応できる体制が必要です。"

  - title: "インターネット・SNS上のいじめを把握しにくい"
    description: "学校外のSNSやインターネット上で発生する問題は、学校が直接把握できない場合があります。子ども、保護者、学校、専門機関が情報を共有し、必要な支援につなげる仕組みを検討する必要があります。"

  - title: "市民が検証できる情報が十分とは限らない"
    description: "行政が公表する認知件数や重大事態件数は重要ですが、件数だけでは施策が実際に機能しているかを判断することが難しい場合があります。個人が特定されない範囲で、いじめの態様、発見の経緯、対応の状況、解消の状況、継続支援の状況等を、必要に応じて集計・匿名化した統計として把握・公表できる情報公開のあり方を検討する必要があります。"

proposals:
  - heading: "まず取り組むこと"
    items:
      - "いじめの認知件数そのものを減らすことを目標にせず、小さな兆候を適切に認知し、早期に対応し、重大化を防ぎ、必要な支援を継続しながら、解消を確認することを重視します。"
      - "学校ごとのいじめ防止基本方針について、児童生徒・保護者が実際に利用できる「相談先・初動対応・教育委員会への相談方法」等を分かりやすく整理して公開します。"
      - "いじめを認知した後の学校内での対応、教育委員会への相談、専門家派遣等について、教職員が迷わず利用できる手順を整理します。"
      - "児童生徒や保護者からの相談だけでなく、本人が相談できない場合でも、周囲の児童生徒、教職員等が把握した小さな兆候を組織的に共有し、必要な確認や支援につなげられる仕組みを整えます。"
      - "インターネットやSNS上のいじめについて、把握した事例の態様、発見の経緯、対応状況等を分析し、情報モラル教育、児童生徒への相談方法の周知、保護者への啓発、学校と関係機関の対応方法の改善に反映します。"

  - heading: "高槻市で取り組むこと"
    items:
      - "現在の学校いじめ不登校対策委員会、教育指導課、高槻市学校問題解決チーム等の既存の仕組みについて、実際の利用状況と対応実績を検証します。"
      - "教職員のいじめ対応に必要な時間と負担を把握し、教職員が担うべき児童生徒との対話・日常的な見守りと、専門職が担うべき心理・福祉・法律等の専門的対応を整理し、適切に役割分担できる環境を整えます。"
      - "いじめの認知件数だけでなく、可能な範囲で、いじめの態様、発見のきっかけ、対応状況、解消状況、継続支援の状況、重大事態として把握・調査した事案の状況等を、個人や学校が特定されない集計単位で統計として公表します。学校間の単純な件数比較やランキングを目的とするものではなく、施策の改善に活用できる情報公開を目指します。"
      - "個人が特定されるおそれがある少数事例については非公表とするなど、子どものプライバシーを守りながら、行政の取組を検証できる情報公開の基準を整えます。"
      - "学校や教職員を単純に評価・批判するための情報公開ではなく、どのような問題が発生し、どのような対応を行い、どこまで解消したのかを市民が確認できる行政評価のための情報公開を目指します。"
      - "いじめの認知から解消・継続支援までの情報を適切に記録し、個人を特定できない形で行政施策の改善に活用できる仕組みを整えます。"
      - "学校、教育委員会、スクールカウンセラー、スクールソーシャルワーカー、弁護士等が、それぞれの役割と権限を踏まえ、本人・保護者の意向や個人情報保護に配慮しながら、必要な情報を適切に共有できるケース対応の仕組みを検討します。"
      - "不登校、心身の不調、自傷・自殺リスク等、いじめとの関連が疑われる場合を含め、児童生徒の安全確保を最優先に、必要な専門機関につなげる支援体制を強化します。"
      - "学校で解決が困難な事案について、教育委員会や専門家による後方支援を早期に開始できる体制を検証します。"

  - heading: "大阪府・国へ要望すること"
    items:
      - "いじめの積極的認知と早期対応を維持しながら、学校現場が過度な事務負担を抱えないための人的・財政的支援を求めます。"
      - "スクールカウンセラー、スクールソーシャルワーカー、スクールロイヤー等の専門職を、必要な事案に対して継続的かつ安定的に活用できるよう、配置・派遣体制の充実と財政的・制度的支援を求めます。"
      - "インターネット・SNS上のいじめへの対応について、学校、保護者、プラットフォーム事業者、警察等が連携しやすい仕組みの充実を求めます。"
      - "いじめの重大事態への対応について、学校・教育委員会が適切かつ迅速に調査・支援を行えるよう、調査の中立性・公平性を確保するための専門的支援、調査体制の確保、必要な財政支援、国のガイドラインの継続的な改善を求めます。"

limitations:
  paragraphs:

    - "いじめの認知件数が増加していることだけから、いじめそのものが増加した、または学校の対応が悪化したと判断することはできません。高槻市教育委員会は、積極的な認知や早期発見・早期対応を認知件数増加の背景として説明しています。"
    - "一方で、認知件数が増加していることを『早期発見が進んだ結果』だけで説明することも適切ではありません。認知件数、重大事態、対応状況、解消状況等を継続的に確認し、実態を多面的に評価する必要があります。"
    - "いじめの情報公開には、児童生徒のプライバシー、被害児童生徒の二次被害、加害児童生徒の個人情報、学校や教職員の個人情報等への配慮が必要です。詳細な個別事案をそのまま公開するのではなく、個人が特定されない統計・匿名化された情報を中心とする必要があります。"
    - "学校、教育委員会、SC、SSW、弁護士、警察等にはそれぞれ異なる役割と権限があります。専門職を配置するだけで問題が解決するものではなく、誰が判断し、誰が対応し、誰が責任を持つのかを明確にする必要があります。"
    - "SNS等のインターネット上のいじめについて、高槻市内でどの程度発生しているのかを現時点で十分な公的データから判断することはできません。そのため、現段階では『SNSいじめが増えている』と断定せず、実態把握と対応強化を政策として進めます。"
    - "目指すのは、いじめの認知件数を機械的に減らすことでも、学校や教職員を責めることでもありません。小さな兆候を見逃さず、重大化を防ぎ、必要な場合には学校だけで抱え込まず、子どもの安全と権利を守る仕組みを継続的に改善することです。"

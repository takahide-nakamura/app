problem:
  paragraphs:
    - "中学校の部活動は大きな転換期にあります。教員の長時間勤務の是正と生徒数の減少を背景に、国は休日の部活動を学校から地域へ移す「地域展開」を進めており、令和8年度から13年度までの改革実行期間に、休日は原則すべての学校部活動で地域展開の実現を目指すとしています。"
    - "高槻市も令和7年度から、教育委員会が自ら運営する地域クラブ活動を休日のみ試行しています。活動場所や用具は学校のものをそのまま使う設計で、送迎が発生しにくい形です。ただし、試行は2種目にとどまり、全面展開の時期や計画はまだ示されていません。"
    - "このまま移行の受け皿づくりが遅れれば、活動の場は民間の習い事やユースクラブへ流れていきます。そうなると、送迎できる家庭、費用を出せる家庭、人気のある種目に機会が偏ります。サッカーや野球のように民間の受け皿がある活動は続けられても、ハンドボールのような種目や、楽器など高額な用具が要る吹奏楽は、学校の場が失われれば受け皿そのものが消えかねません。"
    - "10代のうちに勉強以外の課外活動に取り組む経験は、その後の人生の幅や文化の幅を広げます。教員の働き方改革を進めることと、生徒の課外活動の機会を守ることは、どちらかを諦める話ではありません。その両立を設計するのは、行政と教育委員会の役割です。"

evaluation:
  subjective:
    heading: "現場で感じること"
    paragraphs:
      - "理学療法士として子どもの体や成長に関わってきた立場からも、10代の運動や文化活動の経験は、体力だけでなく、仲間との関わりや続ける力など、その後の人生の土台になると感じています。"
      - "気になるのは、活動の機会が「親が送迎できるか」「家計に余裕があるか」で決まってしまうことです。習い事化が進めば、やりたいことがあっても家庭の事情で諦める子が出てきます。"
      - "教員の負担を減らすこと自体は必要です。ただ、改革のしわ寄せが生徒の機会の減少になってはいけません。学校から地域へ移すなら、移した先の質と公平を行政が担うべきだと考えています。"

  objective:
    heading: "公的資料から分かること"
    paragraphs:
      - "国は令和7年12月に「部活動改革及び地域クラブ活動の推進等に関する総合的なガイドライン」を策定しました。市区町村が認定する「認定地域クラブ活動」の制度が設けられ、希望する生徒を幅広く受け入れること、週2日以上の休養日、可能な限り低廉な参加費、研修を受けた登録指導者による指導などが要件とされています。令和7年改正のスポーツ基本法第17条の2では、地方公共団体に、中学生が地域で継続的に多様なスポーツに親しむ機会を確保する努力義務が明記されました。"
      - "国の令和8年度予算では、部活動の地域展開等に総額57億円が計上され、コーディネーターの配置や指導者謝金、移動手段の確保への補助（国・府・市で各3分の1）のほか、経済的に困窮する世帯の生徒への支援（参加費・保険料等、国2分の1）も用意されています。送迎など移動手段の確保は、国も重点課題に位置づけています。"
      - "高槻市の試行は、教育委員会が運営し、指導者は教委が登録・面談・研修を経て派遣します。平日は学校部活動を継続します。学校管理下の活動ではないため、参加にはスポーツ安全保険（年800円、各家庭の負担）への加入が必要です。市立中学校は18校、生徒数は8,323人（令和6年4月時点）です。試行の対象校数は、市の資料によって「4校」と「6校」の表記があり、確認が必要です。"
      - "費用の目安として、学校部活動の家計負担は月額換算で約2,276円（文部科学省「子供の学習費調査」の二次整理）とされ、地域クラブの参加費は月3,000円未満が大半という国の調査があります。一方、吹奏楽では楽器の価格が高騰し（フルートは10年で1.5〜2倍という報道）、学校備品の老朽化も進んでいて、個人購入の圧力が家庭にかかっている実態が報じられています。"
      - "体験格差の調査（公益社団法人チャンス・フォー・チルドレン）では、世帯年収300万円未満の家庭の子どもの約3人に1人が、直近1年間に学校外の体験活動を何もしておらず、その割合は年収600万円以上の世帯の2.6倍でした。"
      - "先行する神戸市は、条例と基金を設け、令和8年9月に平日を含めた全面展開を行います。会費（平均月約3,200円）に市が月1,500円を補助し（就学援助世帯は3,000円）、保険料は市が負担し、遠い学校には送迎の実証も行っています。"

issues:
  - title: "試行の検証と全面展開の計画が示されていない"
    description: "市の試行は2種目にとどまり、検証の結果や、全面展開の時期・手順は公表されていません。国の改革実行期間（令和8〜13年度）は既に始まっており、計画の明確化が遅れれば、学校現場も家庭も見通しを持てません。"

  - title: "参加費・保険料など家庭負担の設計"
    description: "地域クラブでは参加費や保険料の家庭負担が発生します。学校部活動より負担が増える世帯が出ること、経済的に困窮する世帯への支援をどう使うかが課題です。国の支援制度（参加費・保険料への国2分の1補助）の活用が前提になります。"

  - title: "人気種目への偏りと、マイナーな活動の受け皿"
    description: "民間の受け皿がある人気種目と、学校部活動に依存してきた種目・文化活動とでは、場を失ったときの影響が違います。生徒数の少ない種目は、1校だけでは活動が成り立たず、拠点校方式や複数校の合同クラブといった設計がなければ、選べる活動そのものが減っていきます。"

  - title: "楽器など高額な用具の負担"
    description: "吹奏楽をはじめ、活動に高額な用具が要る分野では、学校備品の老朽化と価格高騰が進み、個人購入の圧力が家庭にかかっています。備品の更新と貸出の仕組みがなければ、費用の壁が参加の壁になります。"

  - title: "送迎・移動の負担"
    description: "活動場所が学校から離れれば、送迎は保護者の負担になります。他自治体の調査では保護者の62％が送迎に負担を感じています。市の現行の試行は学校施設を使う設計で、この負担を抑える形になっており、この原則を展開後も守れるかが課題です。"

  - title: "指導者の確保と質"
    description: "地域展開では、教員に代わる地域の指導者の確保と、研修・登録による質と安全の担保が必要です。指導者の量と質が確保できなければ、活動の継続自体が難しくなります。"

proposals:
  - heading: "まず取り組むこと"
    items:
      - "試行している2種目の検証結果（参加状況、費用負担、指導体制、課題）を公表し、あわせて学校ごとの部活動の現状（種目ごとの部数・加入状況）を市民に示します。"
      - "全面展開の計画と時期を明確にし、国の改革実行期間の中で市がどの順序で展開するのかを示します。"

  - heading: "高槻市で取り組むこと"
    items:
      - "認定地域クラブ活動の市の認定・運営体制を整え、学校施設と学校備品の優先利用を保障し、活動の場を学校に置くことで送迎の負担を生まない設計を原則とします。"
      - "参加費は可能な限り低廉に抑え、経済的に困窮する世帯には国の支援制度を活用して参加費・保険料の負担を軽減します。保険料の家庭負担のあり方もあわせて検討します。"
      - "生徒数が少なく1校では続かない種目や文化活動は、拠点校方式や複数校の合同クラブで受け皿を確保し、人気のある種目だけでなく多様な活動を選べる状態を守ります。"
      - "吹奏楽の楽器など高額な用具は、学校備品の計画的な更新と貸出を進め、個人購入に頼らなくても参加できるようにします。"
      - "地域の指導者の登録・研修と人材バンク、全体を調整するコーディネーターの配置を進め、教員が希望する場合は兼職兼業で関われる仕組みも整えます。"
      - "やむを得ず活動場所が学校から離れる場合は、移動手段の確保への国の補助も活用し、送迎の負担が参加の壁にならない方法を検討します。"

  - heading: "大阪府・国へ要望すること"
    items:
      - "部活動の地域展開への財政支援（コーディネーター配置、指導者謝金、困窮世帯への支援）を、改革実行期間を通じて継続・拡充することを求めます。"
      - "地域クラブ活動と大会・コンクール（中体連等）の参加の仕組みが円滑につながるよう、制度の整備を求めます。"

limitations:
  paragraphs:
    - "試行の対象校数については、市の資料の間に「4校」と「6校」の表記があり、もう1つの試行種目も含め、教育委員会への確認が必要です。学校ごとの部活動の種目別データや加入率は、市の公式情報では公表されていません。"
    - "市内で課外活動の「習い事化」がどの程度進んでいるかを示す公式データは確認できていません。本政策の問題意識は、国の改革の方向と他自治体の調査・事例に基づくもので、市の実態把握が第一歩になります。"
    - "費用に関する数値の一部（学校部活動の月額換算の負担、楽器価格の動向）は、二次整理や報道事例に基づくもので、全国統計として確定した値ではありません。"
    - "地域展開は教員の働き方改革と一体の改革であり、部活動が持ってきた教育的意義（仲間づくりや学校生活とのつながり）をどう継承するかという論点も残ります。機会の確保とあわせて、活動の質の継承を検証し続ける必要があります。"
    - "教員の配置や給与、全国大会の制度など、市だけでは決められない事項も多く、府・国との役割分担の中で進める政策です。"
